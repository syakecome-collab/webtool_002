# ポスカレ

ポスターやおたよりを **撮る**、または予定を **貼り付ける** → 確認して直す → **カレンダーへ一括登録**するツール。

サーバー不要の静的サイト。`index.html` をブラウザで開くだけで動く。

## できること

- 📷 **カメラ撮影・画像アップロード**（最大 5 枚）から Gemini で予定を抽出
- ✍️ **テキスト貼り付け**から抽出（API キー不要）。和暦・全角数字・`10月12日(日)`・`午後2時30分`・`1/5〜1/7` に対応
- 📝 抽出結果を **一覧で確認・修正**（登録前に必ず人が見る設計）
- 📅 **一括登録** — 3 通り
  - `.ics` ダウンロード … iPhone / Android はファイルを開くだけ。Google カレンダーは「設定 → インポート」
  - Google カレンダーの登録画面を選択分だけ順に開く
  - CSV（Google カレンダーのインポート形式）

## 使い方

```sh
# ローカルで開く（ES モジュールを使うので file:// ではなく HTTP で開く）
python3 -m http.server 8000
# → http://localhost:8000
```

GitHub Pages にそのまま置ける（ビルド不要）。

### AI 読み取りを使う場合

1. [Google AI Studio](https://aistudio.google.com/apikey) で API キーを取得
2. 画面の「AI の設定」に貼る

キーはブラウザの localStorage にのみ保存され、送信先は Google の Gemini API だけ。
画像もテキストもこちらのサーバーには一切送らない（そもそもサーバーが無い）。

## 設計上の判断

- **Google の OAuth を取らない。** カレンダーへの書き込み権限は審査・信頼のコストが高いので、`.ics` / CSV / 登録 URL で代替した。結果として Outlook や iPhone 標準カレンダーでもそのまま使える。
- **自動登録しない。** 読み取り結果は必ず確認画面を挟む。AI の読み間違いがそのままカレンダーを汚さないようにするため。
- **AI 無しでも成立させる。** 日本語日付のローカルパーサ（`js/parse.js`）だけで、テキストからの一括登録は完結する。

## 構成

```
index.html          画面
css/style.css       スタイル（ダークモード対応）
js/parse.js         日本語まじりテキスト → 予定（AI 不要）
js/ai.js            画像 → 予定（Gemini API）
js/export.js        予定 → .ics / CSV / Google カレンダー URL
js/app.js           画面の組み立てと配線
tests/              Node の標準テストランナー
docs/research.md    競合調査と収益化の検討
```

## テスト

```sh
node --test tests/*.test.mjs
```
